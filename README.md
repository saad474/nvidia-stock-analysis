# NVIDIA Stock Price Analysis & Prediction

## Overview
End-to-end data science project analyzing NVIDIA's historical stock data 
using machine learning models and clustering algorithms.

## What's Inside
- Full EDA on 10,000+ trading days
- Feature Engineering (Moving Averages, Daily Return, Price Range)
- Statistical Analysis & Normality Testing
- Linear Regression vs Decision Tree comparison
- K-Means & DBSCAN Clustering

## Tech Stack
Python · Pandas · NumPy · Scikit-learn · Matplotlib · Seaborn · SciPy

## Results
| Model             | RMSE   | R² Score |
|-------------------|--------|----------|
| Linear Regression | lower  | higher ✅ |
| Decision Tree     | higher | lower    |

## Dataset
NVIDIA (NVDA) historical stock data
